# Боковой вопрос в Codex CLI

В начатом основном разговоре введите `/btw` или `/side`, затем задайте короткий
боковой вопрос. Для возврата в основной разговор следуйте подсказке TUI: `Ctrl+C`.
Внутри side нельзя открыть ещё один side; команда также недоступна в review mode.
Официальное описание: [Developer commands](https://learn.chatgpt.com/docs/developer-commands?surface=cli#start-a-side-chat-with-side).

Для установленного CLI **0.153.4** локальная проверка 2026-09-08 подтвердила оба
имени команды, требование сначала начать основной разговор и открытие side при
`multi_agent_v2=false`. Включать v2 для этого не требуется. В пустом разговоре
ошибка может называть `/side`, даже если введён его alias `/btw`.

Пользователь отдельно подтвердил, что `/btw` заработал. Автоматическая проверка
ConPTY подтвердила открытие и подсказку возврата, но не полный возврат и штатный
выход: эти попытки завершили по собственному process handle. Причина прежнего
пользовательского сбоя не установлена. Подробности и сохранённые receipts — в
[исследовании](../openspec/changes/adopt-project-memory-and-native-workflows/design.md#3-btw-доказанная-доступность-и-диагностика-состояния).

Side хранит отдельную временную ветку разговора. Обычный `/fork` создаёт другой
разговор с собственной историей. Ни один из них не изолирует файлы: для независимых
изменений используйте [Git worktree](../.agents/skills/isolated-worktree/SKILL.md).
