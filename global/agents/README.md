# Agent source compatibility

The supplied fixed Astra presets have been retired. Select an ordinary native
agent's model and supported reasoning effort directly; see the
[migration and selection guide](../../docs/agent-delegation.md).

This directory remains because the current installation manifest and existing
directory links require its source path. It contains no agent definitions.
Removing that lifecycle slot is separate from deleting redundant presets;
preserve unrelated user agents and the repository's `.agents/skills`.
