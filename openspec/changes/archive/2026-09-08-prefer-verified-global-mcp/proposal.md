## Why

Globally connected MCP tools are available but are not consistently selected for suitable work. The user requests practical checks of every MCP exposed in this session, including subagent access, and global instructions that prefer the useful capabilities across projects.

## What Changes

- Exercise each available MCP integration with bounded representative operations; record usefulness, prerequisites, failures and limits. External connectors receive read-only checks; code/browser writes use owned fixtures.
- Add concise task-specific MCP selection rules to the linked global AGENTS.md source, including project/index checks and honest fallback conditions.
- Verify global instruction loading outside this checkout and actual MCP calls from a named subagent.

## Capabilities

### New Capabilities

- `mcp-tool-selection`: Global, evidence-based selection of applicable MCP tools by parent and child agents.

### Modified Capabilities

None. Existing global availability and instruction precedence remain applicable.

## Impact

The portable instruction source, project decisions, MCP usage documentation and an acceptance report change. Existing global links deliver the instruction update without replacing configuration or restarting services. No new packages, external writes, exhaustive testing of every mutating endpoint, or claim of measured subscription savings is included.
