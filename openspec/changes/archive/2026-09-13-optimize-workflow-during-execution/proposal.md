## Why

Agents can recognize each new failure yet keep paying for the same poorly understood expensive stage. Existing feedback guidance needs to affect the next action during sustained work, including a running operation, without requiring the user to intervene or turning optimization into another project.

## What Changes

- Reassess the method when successive different failures expose one unresolved stage; choose a discriminating observation before another expensive command.
- Apply small, worthwhile workflow improvements immediately within existing task authority. Preserve the promised result, necessary checks and recovery; require no separate change for routine execution improvements.
- Develop and replay uncertain interactions against valid prepared state through the existing automation owner. Compare reset, reuse and restart, and retain full runs when their conditions are necessary.
- Measure costs only when they affect the choice; use bounded parallel investigation when its result can shorten the current path and resource/visibility conditions permit it.
- Verify installed instruction loading separately from observed tool use and independently checked outcomes. Preserve limits on synthetic scenarios and unmeasured speed claims.
