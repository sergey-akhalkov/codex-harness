## Why

The repository has research and user decisions but no portable working-principles document or global instruction activation. The user wants the useful philosophy from opencode-kit adapted to complete specification delivery, P0/P1 prevention, and development speed, and loaded in Codex sessions across repositories.

## What Changes

- Create one concise, self-contained source of reusable working principles, with explicit OpenSpec completion semantics.
- Adapt review, production-readiness, and retry rules to the agreed specification and concrete risks, as confirmed by the user.
- Record source provenance, coverage of the original principles, and the reasons for adaptations outside the always-loaded text.
- Connect the source to the current user's global Codex AGENTS.md without replacing existing instructions or changing unrelated configuration.
- Verify the actual initial prompt from separate working directories and document activation, update, and rollback boundaries.

## Capabilities

### New Capabilities

- `global-working-principles`: A portable philosophy and its activation as global Codex instructions, with auditable adaptation and verified cross-repository loading.

### Modified Capabilities

None.
