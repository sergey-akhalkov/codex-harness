## Why

The user requires relevant skills to be used, rather than treated as optional aids. The global instructions currently say to load skills when beneficial without an explicit mandatory selection and execution rule.

## What Changes

- Require main and child agents to assess available skills against the actual task, load applicable instructions, and follow their workflow.
- Preserve skill scope, invocation restrictions, progressive loading and instruction precedence; familiarity with a task is not a reason to bypass its applicable skill.
- Deliver through the existing global AGENTS.md link and verify native loading outside the harness.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `global-working-principles`: Add mandatory relevant-skill use across projects and subagents.

## Impact

Portable principles, durable user decisions, and bounded acceptance evidence. No skill packages, model routing, MCP registrations or services change.
