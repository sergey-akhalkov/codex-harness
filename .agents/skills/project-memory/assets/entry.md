# Topic

- Statement: the reusable fact or decision.
- Scope: where and under which conditions it applies.
- Status: confirmed (user decision), verified (observation), tentative, or superseded.
- Basis: user confirmation or a relative link to source/check evidence.
- Date / source identity: confirmation date for decisions; checked revision and relevant dirty inputs for technical observations.
- Recheck when: inputs that invalidate technical applicability, if relevant.

For a command, include exact executable/arguments, project-relative cwd, preparation and current source definition. Keep historical successful execution separate from the current check result; use the project's existing verification record when available. Remove inapplicable fields rather than inventing evidence.
